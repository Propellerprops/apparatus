# Apparatus Studio — apparatus.ge

Website for Apparatus Studio, Tbilisi — Georgia's first large private film studio.

- `index.html` — homepage (logo shutter animation)
- `studio.html` — the stage: interactive 3D skeleton + photo gallery
- `catalog.html` — equipment catalog with quote list
- `photos/` — web-optimized images (keep new photos ≤ ~1400px wide, JPEG q80)

Deployed via Netlify; every commit to `main` goes live automatically.
